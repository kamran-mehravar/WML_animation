TIRAMISU — Visual Asset Lock v1.9

This archive contains byte-identical copies of existing image files. Previously approved source images are preserved byte-for-byte. The newly approved dock and workboat references are included.
APPROVED means the reference was accepted in the conversation, not that every incidental item in the background of an image is approved. PENDING assets cannot be used as final approved backgrounds.

Production rules:
1. Reuse approved image files, not text-only approximations. Composite independently and preserve geometry, colors and faces.
2. No WML labels or logos on physical equipment, clothing or accessories. WML branding belongs in software introduction only if appropriate.
3. Basket body brick red; yellow applies to the numbered basket tag, never to the plastic body.
4. Wax: red = red wine, yellow = white wine, green = rose. Tags independently: green = sea; blue = cellar; yellow = sensor bottle or basket ID; red = other experimental bottles (less common).
5. No QR tags, separate wax medallions, generic wide sensor bags or invented equipment.
6. Cage loading takes place at Scarlino. The exact loading arrangement and vessel must be verified before final animation; do not infer load safety from storage capacity.
7. Do not mark a generated scene approved before user review. Prior dock generations with incorrect assets are excluded.
8. Verify fixed reference file hashes using manifest.json. For animation, visual consistency still requires shot-by-shot review; this is an asset registry, not a rigged 3D model library.
